# Security Policy

Only the latest release is supported.

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/jabbrwcky/gh-sub-pattern/security/advisories/new)
or by email to jens@hausherr.net. Do not open public issues for security problems.

Patterns that are broader than requested (e.g. matching refs or repositories the user did
not ask for) are treated as security issues.
